BooKeeper - это десктопное приложение на Python с графическим интерфейсом для учёта прочитанных книг. Позволяет добавлять, редактировать и удалять записи, сохранять заметки и оценки.

Управление:
  Ctrl + S	Сохранить книгу
  Ctrl + N	Очистить форму (новая запись)
  Delete	Удалить выбранную книгу
  Ctrl + Q	Закрыть приложение

Возможности:
  Добавление книг — название, автор, жанр, количество страниц
  Статус чтения — Читаю, Прочитана, Брошена
  Оценка — от 1 до 5
  Заметки — текстовое поле для впечатлений и цитат
  Даты — начало и окончание чтения
  Редактирование — изменение любой записи
  Удаление — с подтверждением
  Автосохранение — в JSON-файл
  Горячие клавиши — для быстрого управления

Технологии:
  Python 3
  Tkinter — графический интерфейс
  JSON — хранение данных
  os / datetime — работа с файлами и датами

Системные требования:
  ОС: Windows / macOS / Linux
  Python 3.6+ (для запуска из исходников)
  RAM: от 50 МБ
  Дополнительно: Tkinter (входит в стандартную установку Python)

Зависимости:
  Отсутствуют — используется только стандартная библиотека Python
  
Установка и запуск:
  При первом запуске автоматически создастся файл BooKeeper.json для хранения данных.
  Способ 1 (из исходников):
    1. Установите Python 3.6+
    2. Скачайте BooKeeper.py
    3. Запустите: python BooKeeper.py
    
  Способ 2 (exe-файл):
    1. Зайдите в репозиторий
    2. Найдите BooKeeper.exe
    3. Скачайте
    4. Создайте папку BooKeeper на рабочем столе
    5. Перекиньте туда экзешник
    6. Запустите BooKeeper.exe
